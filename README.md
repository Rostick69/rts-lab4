# Канал передачи данных с временными ограничениями

Практическая работа № 4 по дисциплине «Системы реального времени». Вариант 2 — промышленная сеть контроллеров.

Цель работы — рассчитать время передачи, задержку доставки и джиттер сообщений, а также проверить соблюдение дедлайнов при приоритетном арбитраже.
