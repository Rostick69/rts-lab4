# Канал передачи данных с временными ограничениями

Практическая работа № 4 по дисциплине «Системы реального времени». Вариант 2 — промышленная сеть контроллеров.

## Запуск в Visual Studio

Откройте `rts-lab4.sln` в Visual Studio с компонентом «Разработка на Python». Выберите среду Python 3.10 или новее и нажмите **Ctrl+F5**. Программа использует только стандартную библиотеку. Стартовый файл — `src/main.py`.

## Запуск в терминале

Из корня проекта:

```text
python src/main.py
python src/main.py data/example.csv
python -m unittest discover -s tests -v
```

Параметры шины хранятся в `data/channel.csv`; другой файл можно передать через `--channel путь.csv`. Набор по умолчанию — `data/variant2.csv`. В `docs` находится отчёт с результатами, формулами и листингом.

## Что показывает программа

Сообщения выпускаются с момента 0 через заданные периоды. На свободной шине первым передаётся ожидающее сообщение с наименьшим номером приоритета. Начатая передача завершается полностью. Программа моделирует один гиперпериод и для каждого потока выводит время передачи, задержку без очереди, максимальную задержку доставки, джиттер и результат проверки дедлайна. Джиттер — разность максимальной и минимальной задержек экземпляров одного потока.

Для варианта 2 максимальная задержка сообщения «Состояние линии» равна 7,3 мс при дедлайне 8 мс. Остальные три потока хотя бы один раз нарушают срок. В контрольном примере из методички все три потока укладываются в заданные сроки.
